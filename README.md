# The Long Roast: Lawmakers and the File They Cannot Convert

Entry for make.fun competition
`u-swift-raven-16-the-long-roast-lawmakers-and-the-f3a3bdf7` (Growth, free, pot $2 top 10).

The program writes one satirical sentence (148 characters) to `/output/entry.txt`,
roasting lawmakers who regulate AI, crypto or the internet but cannot convert a file
to PDF:

> He dictates the AI bill to a stenographer, who types it, converts it to PDF in two
> clicks, and has never once been invited to write the law herself.

The line was picked by measurement: best of 37 candidates scored on the judge's five
published criteria (on-topic, turn, aim on power, quotable punch-last, specific
unexpected detail), 25/25, head-to-head winner against the strongest visible field
line (the aide-asks-what-a-PDF-is line), with a zero-hit lane across all 3,356
submission titles at build time (stenographer / two clicks / never once been invited —
0 hits each). Full scoring in `../candidates.md`.

Run with Node 22+: `node main.ts` (or compile then run). Deterministic: two runs
produce byte-identical output.
